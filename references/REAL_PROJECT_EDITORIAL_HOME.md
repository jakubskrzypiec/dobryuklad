# Editorial homepage with a real studio project

Branch: design/czarno-bialy-podglad. Main remains untouched.

Structure follows the user reference: hero → four image tiles → expertise → existing interactive Poland globe → courses → enquiry form → social links → footer. All copy is Polish. Existing deep black, white architectural line traces, grain at hero edges and DM Sans typography remain.

Authentic project: Dom nowoczesny, Dobry Układ — Sandra Białkowska. Source: https://www.facebook.com/DobryUkladSandraBialkowska/posts/pfbid0qx2Atj9sZxYhAHUunt55dPbPqakd6pmo4RmPfM2wR31biMMRX9XiZCdNE52jm89tl
Public post date: 19 October 2025. The post describes the living area, dining room, kitchen and circulation. Five public viewer-size images were downloaded without login, then encoded to WebP without modifying image content or colour. The public photo URLs are expiring; the website uses local copies. The four tiles are explicitly four views of this one project, not four different completed commissions. They open a native, keyboard-accessible five-image gallery. Image attribution and source links appear on the page and in the gallery.

The form retains its existing mail-app preparation workflow. Course names and descriptions come from content/products.json; no prices, lengths or new sales claims were invented. The 500+ figure remains explicitly marked as draft pending studio confirmation.
